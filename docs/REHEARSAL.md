# 행사 전 리허설 체크리스트

README 의 "확인하지 못한 것"을 **실제 폰으로 직접 확인**하는 순서입니다. 약 20~30분, 코드 수정 없이 합니다.
행사 하루 이틀 전, 실제로 쓸 **스크린(노트북/TV)과 교회 와이파이**에서 하는 것이 가장 좋습니다.

## 준비물

- 스크린에 띄울 기기 1대 (실제 행사에서 쓸 것 그대로)
- 폰 **5대 이상**. 가능하면 아이폰(사파리) 2대 + 안드로이드(크롬) 2대 + 카카오톡으로 QR 링크를 여는 폰 1대
- 퀴즈 1개 (3문제짜리 짧은 것이면 충분. 예: 6문제 상식 퀴즈)
- 이 표를 인쇄하거나 옆 화면에 열어 두고 ✅/❌ 표시

## 1단계 · 입장 (5분)

| # | 할 일 | 통과 기준 | 결과 |
|---|---|---|---|
| 1-1 | 스크린에서 PLAY → 퀴즈 선택 → 시작하기 | PIN 6자리와 QR 이 보임 | |
| 1-2 | 폰 카메라로 QR 스캔 | 별도 로그인 없이 닉네임 입력 화면이 바로 뜸 | |
| 1-3 | **카카오톡으로 링크를 보내서** 인앱 브라우저로 열기 | 하얀 화면 없이 입장 화면이 뜸 | |
| 1-4 | 닉네임 + 캐릭터 + 색 고르고 참가 | 스크린 로비에 캐릭터가 나타남 | |
| 1-5 | 같은 닉네임으로 한 대 더 입장 시도 | 거절 안내가 나옴 | |

## 2단계 · 진행 (10분)

| # | 할 일 | 통과 기준 | 결과 |
|---|---|---|---|
| 2-1 | 시작 → 카운트다운 동안 폰 버튼 누르기 | 카운트다운 중에는 눌러도 답으로 안 잡힘 | |
| 2-2 | O/X 문제 | 폰에 버튼 2개, 스크린에 문제 글이 나옴 | |
| 2-3 | 4지선다 문제 | 폰에 색 버튼 4개, 눌렀을 때 "제출 완료!"가 보임 | |
| 2-4 | 정답 공개 → 점수판 | 순위가 뒤바뀌는 애니메이션이 끊기지 않음 (저사양 폰 포함) | |
| 2-5 | 폰 한 대의 **화면을 껐다 켜기** (진행 중) | 다시 켰을 때 현재 문제 화면으로 돌아옴 | |
| 2-6 | 폰 한 대를 **다른 앱으로 갔다가 복귀** | 같은 닉네임으로 이어서 참가 상태 유지 | |
| 2-7 | 폰 한 대의 와이파이를 껐다 켜기 | 자동 재연결 (안 되면 새로고침으로 복구되는지) | |

## 3단계 · 소리와 시상식 (5분)

| # | 할 일 | 통과 기준 | 결과 |
|---|---|---|---|
| 3-1 | 스크린에서 소리 켜기 → 로비/문제/점수판/시상식 BGM 듣기 | **직접 듣고** 분위기에 어울리는지 판단. 안 맞는 곡은 메모 | |
| 3-2 | 스크린 음량 | 학생들 목소리에 묻히지 않고 귀가 아프지 않음 | |
| 3-3 | 최종 결과 → 시상식 | 커튼, 3등→2등→1등, 폰에 각자 순위 | |
| 3-4 | 폰에서 순위 확인 | 스크린에서 발표되는 순간 폰에도 맞게 나옴 | |
| 3-5 | 폰의 "동작 줄이기" 설정을 켜고 한 번 더 | 움직임이 줄어도 진행에 문제 없음 | |

## 4단계 · 진행자 실수 대비 (3분)

| # | 할 일 | 확인할 것 | 결과 |
|---|---|---|---|
| 4-1 | 진행 중 **스크린 화면을 새로고침** | 약 10초 뒤 폰에 "진행자가 나가서 퀴즈가 끝났어요"가 뜸(의도한 동작). 이때 어떻게 다시 시작할지 연습: PLAY → 새 방 → QR 다시 안내 | |
| 4-2 | 스크린 기기가 절전으로 꺼지지 않는지 | 10분 이상 두고 확인. 꺼지면 절전 해제 설정 | |

## 알려진 한계 (리허설에서 놀라지 않도록)

- 진행자가 페이지를 나가거나 새로고침하면 10초 뒤 방이 끝남 (의도한 동작, README 에 기록)
- 폰에는 문제 글이 안 나옴. 스크린이 안 보이는 자리의 참가자는 읽을 수 없음
- 수십 명 동시 접속은 시험한 적 없음. 인원이 많으면 리허설 때 폰 대신 **여러 사람이 동시에 입장**해서 확인
